# 波点音乐 · MyGo Music 插件

把[波点音乐](https://www.bodian.com/)（酷我）接进 [MyGo Music](https://github.com/egoist/mygo-music)：
搜索、首页推荐、每日推荐、排行榜、歌单广场、我的歌单 / 收藏、我喜欢的音乐、评论、歌词，以及
按音质取流播放。扫码登录，登录态和本机 devid 都存在插件自己的存储里。

## 安装

插件是一个文件夹，`plugin.json` 在顶层。任选一种：

- 设置 → 插件 → `+` → 从文件夹安装，选中本目录
- 或者把本目录复制到 MyGo Music 的插件目录：
  - Windows：`%APPDATA%\MyGo Music\plugins\bodian`
  - macOS：`~/Library/Application Support/MyGo Music/plugins/bodian`

装好后在侧栏左上角的来源切换里选「波点音乐」。

## 登录

侧栏左下角账号处点登录，用波点音乐 App 扫码并在手机上确认。登录不是必须的：
搜索、歌单、免费歌曲都能直接播；VIP 歌曲需要登录且有对应权限。

> 波点的 token 绑定本机 devid，插件把 devid 持久化在自己的存储里。清掉插件数据后需要重新登录。

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 搜索 | 单曲 / 歌手 / 专辑 / 歌单；输入框为空时给出热搜词 |
| 首页 | 每日推荐、波点实验室、听点不一样的、主题歌单、推荐歌单、排行榜 |
| 每日推荐 / 排行榜 / 歌单广场 | 侧栏入口；歌单广场按页浏览，可一直翻下去 |
| 我的歌单 | 新建、重命名、删除、加歌、移出歌曲 |
| 收藏 | 收藏/取消收藏别人的歌单、专辑，关注/取关歌手 |
| 我喜欢的音乐 | 喜欢/取消喜欢 |
| 评论 | 读热门评论、给评论点赞 |
| 歌词 | LRC |
| 播放 | 按 MyGo 的音质设置取流：标准=128k MP3；高=波点的 hires 档（有 FLAC 给 FLAC，没有给 320k MP3）；无损=FLAC |

## 已知限制

- 波点对有 FLAC 的歌**只提供 128k 的 MP3**，所以「高」音质对有损歌曲可能是 FLAC、也可能是 128k MP3（按波点实际返回）。
- 没有播客、没有私人 FM/漫游电台。
- 不能给歌曲发表评论（波点 App 的这个接口没有公开），只能读和点赞。
- 歌单内拖动排序不支持（波点 API 没有该接口）。
- 繁体/异体字歌名与波点曲库的匹配以波点搜索为准。

## 开发

`index.js` 是唯一的源文件，无需构建。改动后重启 MyGo Music 即可（或在 设置 → 插件 里重载）。
调试时可以直接用 MyGo 的插件运行时加载本目录、调用各导出函数，无需开界面。
