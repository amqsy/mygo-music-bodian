# 波点音乐-QQ音乐简洁版 · MyGo Music 插件

把[波点音乐](https://www.bodian.com/)接进 [MyGo Music](https://github.com/egoist/mygo-music)：
搜索、首页推荐、每日推荐、排行榜、歌单广场、话题、音乐日历、我的歌单 / 收藏、
我喜欢的音乐、评论、歌词，以及按音质取流播放。扫码登录，登录态和本机 devid 都存在插件自己的存储里。

## 安装

插件是一个文件夹，`plugin.json` 在顶层。任选一种：

- 设置 → 插件 → `+` → 从文件夹安装，选中本目录
- 或者把本目录复制到 MyGo Music 的插件目录：
  - Windows：`%APPDATA%\MyGo Music\plugins\bodian`
  - macOS：`~/Library/Application Support/MyGo Music/plugins/bodian`

装好后在侧栏左上角的来源切换里选「波点音乐」。

从 GitHub 安装时，仓库加上 topic `mygo-music-plugin` 就会出现在
[官方插件列表](https://music.egoist.dev/zh/plugins)：

```
mygo-music://install-plugin?repo=<owner>/mygo-music-bodian
```

## 登录

侧栏左下角账号处点登录，用波点音乐 App 扫码并在手机上确认。登录不是必须的：
搜索、歌单、免费歌曲都能直接播；VIP 歌曲需要登录且有对应权限。

> 波点的 token 绑定本机 devid，插件把 devid 持久化在自己的存储里。清掉插件数据后需要重新登录。

| --- | --- |

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 搜索 | 单曲 / 歌手 / 专辑 / 歌单；输入框为空时给出热搜词 |
| 首页 | 每日推荐、猜你想听、波点实验室、听点不一样的、主题歌单、心动收藏相似推荐、推荐歌单、排行榜 |
| 每日推荐 / 排行榜 / 歌单广场 | 侧栏入口；歌单广场按页浏览，可一直翻下去，也能按分类（主题/流派/语言/心情/场景/年代）找 |
| 电台 | 猜你想听一条接一条；场景电台：开车、运动、学习、睡前，由波点的场景接口给出 |
| 话题 | 波点听众的话题，点开就是一个歌单 |
| 音乐日历 | 每天一条音乐故事，卡片上带歌名和歌手，点开是一张以那首歌开头的小歌单 |
| 我的歌单 | 新建、重命名、删除、加歌、移出歌曲 |
| 收藏 | 收藏/取消收藏别人的歌单、专辑，关注/取关歌手 |
| 我喜欢的音乐 | 喜欢/取消喜欢 |
| 评论 | 读热门评论、给评论点赞 |
| 歌词 | LRC |
| 播放 | 按音质取流：标准=128k MP3；高=波点的 hires 档（有 FLAC 给 FLAC，没有给 320k MP3）；无损=FLAC |

## 已知限制

- 波点对有 FLAC 的歌只提供 128k 的 MP3；「高」音质先要 hires 档：有 FLAC 给 FLAC，没有则给 320k MP3，若连 320k 也没有才退到 128k（按波点实际返回）。
- 单张歌单最多读取 1000 首；收藏的歌单最多列出 1000 张。超出的部分不会显示。
- 排行榜、话题和音乐日历是页面，不是可收藏的歌单，所以它们没有「收藏」按钮。


## 开发

`index.js` 是唯一的运行文件，不需要构建；`locales/zh-CN.json` 是英文原文到中文的翻译，
插件在代码里写英文、用 `host.t()` 取译文。

```bash
npm test     # node --test：mock 掉 host 和 fetch，离线跑
npm run check  # 语法检查 + 测试
```

测试覆盖：搜索/歌单/评论/歌词的字段映射、会话进 query 与过期处理、迟到 -101 不覆盖新会话、
歌单源探测（含话题歌单的 5/13/4 顺序）、搜索歌单不误判为自己的、专辑收藏状态、
取流阶梯（FLAC / 320k / 128k / 加密格式与非 http(s) 地址跳过）、改名 PUT、删除 DELETE、
扫码登录流程、音质覆盖、HTTP 状态与空首页报错，以及「每一条界面文案（含清单）都有中文翻译」。
